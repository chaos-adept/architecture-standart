### <a name="_qmphm5d6rvi3"></a>**Решение**

Как решение предлагается расширить возможности сервиса ведения заявок,
предоставив еще API для системы кол-центра банка для получения актуальных данный по ставкам,
извещение об обновлении ставок будет присылаться по топику кафки, а также экспорт через периодическую отсылку email.

На схемах новые блоки выделены ярким цветом.

### <a name="_bjrr7veeh80c"></a>**Альтернативы**

Как альтернатива можно сделать извещение по файлам, как для внешней так и для внутренней системы,
это будет проще, но снизит качество предоставления услуг кол-центром.

**Недостатки, ограничения, риски**

- основной недостаток в том, что данные всегда будут немного отставать у внешней системы.
